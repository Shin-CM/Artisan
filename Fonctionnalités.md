# Fonctionnalités — Artisan

Application desktop **Tauri + React + SQLite** (offline-first), interface en **français**. Le nom commercial affiché est **Artisan** ; les identifiants techniques (modules `invoicies.*`, fichier local **`invoicies.sqlite`**, variables **`INVOICIES_*`**) restent inchangés pour la compatibilité. Licence **MIT** (fichier [`LICENSE`](LICENSE)) : logiciel **libre**, sans abonnement ni palier payant.

Présentation GitHub et documentation racine :

- **`README.md`** : vitrine GitHub du projet, positionnement, démarrage rapide et liens de documentation.
- **`docs/Histoire-du-projet.md`** : origine d’Artisan, passage en open source et souhaits du créateur pour la suite du projet.

## Interface utilisateur

- **Thème (Clair / Sombre / Système)** : stocké sur le workspace SQLite ; à l’ouverture d’un espace, **`openWorkspace`** et la réhydratation **`refreshActiveWorkspace`** au montage du provider rechargent l’enregistrement complet via **`get_workspace`** (et mettent à jour la liste en mémoire) pour éviter de retomber sur **Système** à cause d’une ligne de liste sans champ **`theme`** à jour.
- **En-têtes de page** : le court texte d’introduction n’est plus sous le titre ; il est dans une tooltip Radix (survol **et** focus clavier) via un bouton **icône seule** « Information » (**Lucide `Info`**) à droite du titre. Composant **`PageTitleWithInfo`** (`src/components/PageTitleWithInfo.tsx`) — à réutiliser pour toute nouvelle page qui expose ce type d’aide. PWA tablette : **`pwa-tablet/src/components/PageTitleWithInfo.tsx`**, **`TooltipProvider`** dans **`main.tsx`**, dépendance **`@radix-ui/react-tooltip`**.

## API locale & PWA tablette (LAN)

- **Module Marketplace (optionnel, expérimental)** : identifiant manifeste **`invoicies.local-tablet-api`** (version **0.1.0**, capacité **`local_tablet_api`**). L’activation se fait sous **Marketplace → Intégrations** ; tant que le module est inactif pour l’espace, l’entrée **Paramètres → Plugins → API tablette** est masquée et la route **`/settings/local-api`** affiche un renvoi vers la fiche module (fiche avec encart *extension expérimentale*). La désactivation du module coupe aussi l’écoute HTTP (**`local_api_set_enabled(false)`**) sur l’app Tauri lorsque c’est possible. **Migration** : si **`local_api_settings.api_enabled`** était déjà à **1** avant mise à jour, une ligne **`plugin_registry`** active est créée pour chaque espace afin de conserver l’accès aux réglages.
- **Serveur HTTP** intégré au binaire (**Axum** + **Tokio**), écoute **`0.0.0.0`** sur le port paramétrable (défaut **3847**) ; une fois le module Marketplace activé pour l’espace, l’écoute se pilote depuis **Paramètres → Plugins → API tablette**. Endpoints **`/api/v1/health`**, **`/api/v1/auth/pair`** (pairing QR **5 min**, usage unique), **`/api/v1/auth/login`** (mot de passe opérateur **Argon2** + identifiant d’espace), **`/api/v1/clients`** (GET/POST), **`/api/v1/products`**, **`/api/v1/tax-rates`**, **`/api/v1/quotes`** (GET liste, GET détail, POST, PATCH) ; **JWT** + table **`local_api_sessions`** (révocation) ; secret **`local_api_jwt_secret.bin`** dans les données app ; **CORS** permissif pour usage sur tablette.
- **IPC desktop** : `local_api_get_status`, `local_api_set_enabled`, `local_api_set_port`, `local_api_start_pairing`, `local_api_list_sessions`, `local_api_revoke_session`, `local_api_set_operator_password` ; page **`SettingsLocalApiPage`**, route **`/settings/local-api`**, dépendance **`qrcode.react`** pour afficher le QR.
- **PWA séparée** : dossier **`pwa-tablet/`** (Vite 7, React 19, Tailwind 4, **vite-plugin-pwa** 1.x, **@radix-ui/react-tooltip** pour les tooltips d’en-tête) ; connexion par **collage JSON / caméra** (`BarcodeDetector` si disponible) ou **mot de passe** ; listes **clients** et **devis**, création client, création / édition devis simplifiée ; **`npm run dev`** / **`npm run build`** dans **`pwa-tablet`** (servir **`dist/`** sur le réseau ou ouvrir depuis une URL interne).
- **Website — intégration PWA tablette** : le site **`website/`** expose une page **`/tablette`** (accès + consignes d’installation) et publie la PWA sous **`/tablet-app/`** via le script **`npm run sync:tablet-pwa`** ; le build website lance cette synchronisation automatiquement avant **`next build`**. La build PWA accepte un sous-chemin via **`VITE_TABLET_BASE`** (ex. `/tablet-app/`).
- **Refactor Rust** : fonctions **`*_conn`** dans **`clients.rs`**, **`catalog.rs`**, **`tax_rates.rs`**, **`quotes.rs`** pour que l’API réutilise la même logique que les commandes Tauri (sans duplication) ; migrations incrémentales SQLite (**ALTER TABLE**, tables dérivées, API locale, stock, projets, etc.) dans **`src-tauri/src/migrations/incremental.rs`** (`run_incremental_migrations`), **`column_exists`** dans **`migrations/helpers.rs`** ; bootstrap **`CREATE TABLE`** initial dans **`db.rs`** avec **`peek_next_document_number`** / **`next_document_number`**.

## Technique

- **Build front** : routes métier en **lazy loading** (`React.lazy` + `Suspense` dans `App.tsx`) ; **xlsx** chargé **à la demande** dans le Data Manager (import Excel clients) ; **manualChunks** Vite (`recharts`, `@react-pdf`, `xlsx`, `lucide-react`, `@radix-ui`) pour un **premier chargement** plus léger.
- **Paramètres → Branding** : page allégée (`SettingsBrandingPage`) ; bloc **police PDF** (`SettingsBrandingPdfFontSection`), panneau **polices dans l’espace** (`WorkspacePdfFontsInstalledPanel`), carte **logo / en-tête** (`BrandingLogoHeaderCard`), hook **`useBrandingLogoPreview`**, helpers **`brandingWorkspaceFonts`** (fusion / suppression bibliothèque).
- **Éditeurs devis / factures** : pages minces **`QuotesPage`** / **`InvoicesPage`** ; état dans **`useQuotesPage`** / **`useInvoicesPage`**, rendu dans **`QuotesPageView`** / **`InvoicesPageView`**, persistance PDF/CRUD extraite (`quoteEditorPersistActions`, `invoiceEditorPersistActions`). UI partagée sous `src/pages/documentEditor/` (tableau des lignes articles + TVA + notes, récapitulatif HT/TVA/TTC, panneau d’import des lignes depuis un devis côté facture, formatage devise / regroupement devis par jour) ; **`ArticleLinePicker`** (popover + arbre catégories pour les besoins qui ne gèrent qu’un `articleId`) ; **`ArticleVariantLinePicker`** (lignes document : article **ou** variante, arbre catégories repliable).
- **Volets d’aide (UI)** : logique responsive mutualisée via le hook **`useResponsiveHelpAside`** (ouverture par défaut en desktop, fermeture auto en petit écran, toggle icône homogène) pour garantir un comportement identique entre **Clients** et **Paramètres → Espace de travail**.
- **Glisser-déposer catalogue / clients** : **`@dnd-kit`** (`core`, `sortable`, `utilities`) ; helpers d’ordre articles `articleOrder.ts`.
- **Aperçu PDF** : en **navigateur**, ouverture dans un nouvel onglet (blob) ; sous **Tauri**, écriture dans `pdf_preview_cache` sous le dossier données app + ouverture avec la visionneuse système (`write_pdf_preview_temp` + plugin `opener`), car `window.open` sur blob ne convient pas à la webview desktop ; capacité **`opener:allow-open-path`** avec scope `$APPLOCALDATA/pdf_preview_cache/**` (sinon le plugin refuse le chemin).
- **Export / aperçu devis & factures** : `loadPdfCommonContext` relit l’espace via **`get_workspace`** pour appliquer le **`profile_json` à jour** (branding, dont **police PDF**) et **`list_plugins`** pour savoir si le module **typo PDF** est actif (`pdfTypographyModuleActive` dans le contexte PDF). Contexte PDF inclut **`workspaceId`** pour résoudre les polices **`workspace`** via `read_workspace_asset_base64`. `Font.register` avec data URL **`font/ttf`** / **`font/otf`** — **trois faces** (normal, gras, italique) pour polices **fichier** ; pas de 4ᵉ face « gras italique » dupliquée sur le même buffer (évite des plantages fontkit du type `undefined.tables`). **Catalogue** : URL **BoldItalic** enregistrée si présente ; en cas d’échec d’enregistrement, **repli** sur les trois faces de base. **Nom de famille stable** par police (hash) pour éviter les collisions react-pdf ; échecs de chargement **remontés** (plus de repli silencieux sur Helvetica). Styles PDF : **couleurs / tailles** dans `pdfVariantStyles`, **emphase** (poids / style) fusionnée par bloc via `pdfTypography` + `QuoteInvoicePdf`.
- **Développement navigateur** (`npm run dev` sans Tauri) : bandeau « mode navigateur », IPC simulé en mémoire (`src/lib/apiMock/`, point d’entrée `index.ts`, commandes découpées par domaine dans `handlers/` + registre `mockHandlersRegistry.ts`) pour parcourir toute l’UI sans rechargement type build desktop ; pas de persistance (réinitialisation au F5).
