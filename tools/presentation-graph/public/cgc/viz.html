Emplacement réservé à l’export CodeGraphContext

Remplacez ce fichier public/cgc/viz.html par le HTML généré par la CLI (option --viz), ou copiez votre export sous ce nom après indexation du dépôt parent.

  1. Depuis la machine : pip install codegraphcontext (ou pipx).
  2. codegraphcontext index /chemin/vers/Artisan
  3. Générer une viz (ex. appels ou recherche) avec --viz, puis copier le fichier produit ici sous le nom viz.html.
